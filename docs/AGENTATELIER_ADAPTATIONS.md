# AgentAtelierR 思路在本地 Mac 版的取舍

参考：https://github.com/onion-aqua/AgentAtelierR 。以下是独立实现的思路适配，不是照搬其源码或完整功能。原版 UI、角色资源与独立动作仍以 ryza-ai-revive 为准。

## 本轮补齐

| 思路 | 本项目实现与边界 |
| --- | --- |
| 流式对话 | XHR SSE 增量显示正文，屏蔽思考、工具、状态标签及不完整控制标签；流中断不提交半句。完成后才应用游戏状态、记录和配音。 |
| 取消生成 | 生成期间再次点击发送或按 Escape 取消；中止请求并使迟到结果失效。取消的本轮不进入长期记忆。 |
| 语言一致性 | 每轮固定显示语言、配音语言和模式。明显语言不符最多一次纯文本修正，不重复游戏状态操作；短名字、汉字短句保守放行。不能保证识别所有语言错误。 |
| 译文复用 | 翻译按来源、目标语言保存到对应聊天记录；翻译错语种最多重试一次，共享总超时。保留会话级有限缓存与取消检查。 |
| 记忆并发可靠性 | 单次归纳共用请求，只移除已成功处理的待办；失败保留，新增待办不误删。读档或手工修改使旧请求失效。快照保存待办，兼容旧存档。 |
| 上下文预算 | 归纳请求按完整对话项缩减，保持合法 JSON；已有记忆已超预算时保留待办等待处理。仍有容量上限，不是无限记忆。 |
| 本地音频校验 | 播放前检查 WAV 容器、格式和数据块长度；错误负载不创建音频地址。不会自动切换付费服务。 |

## 此前已适配，继续沿用

| 思路 | 本地实现 |
| --- | --- |
| 引擎能力与音色配置 | 按语言、普通/ASMR 模式选择本地音色及演绎强度，未安装引擎标明不可用。 |
| 情绪演绎 | CosyVoice 中文使用情绪指令；日语沿用本机实际表现较好的 Qwen3-TTS。中性语句不强加情绪。 |
| 参考音频与音量 | 本地参考音色，CosyVoice 有限整段增益和峰值余量，保留句内动态。没有经过主观听测就不宣称音质提升。 |
| 配音队列与打断 | 句级预取、取消转写/翻译/合成、丢弃迟到音频。文本 SSE 不等于音频 PCM 流式输出。 |
| 记忆检索 | 摘要与条目两层、关键词相关度选择、重要条目保护；不额外加载向量模型。 |
| 动作协调 | 保留独立手臂、躯干和随机姿势，通过轨道/语义归属及过渡门控避免竞争。 |

## 不直接迁入

- Android 专用 MNN 推理、系统权限与后台机制：使用 macOS/MLX 和现有桌面生命周期。
- 全套云 TTS 服务、云端代理与远程工具：增加费用、凭据和维护负担；本机没有必要为每个服务再装引擎。
- 虚拟手机、多人私聊、新角色等产品功能：属于新玩法与界面设计，会改变用户要求保留的原版体验。
- 模型微调、声音转换链：不能仅靠框架移植保证更像角色，额外延迟及空间成本需要单独音频对照验证。

## 验证

`node scripts/dialogue_reliability_regression.js` 覆盖 SSE 分片、嵌套隐藏标签、取消、截断流、语言修正次数、记忆竞态/读档、无效音频。旧源对照四组失败，修改后四组通过。

既有存档、长期记忆、双语配音、音色配置、语音队列等回归通过；`python3 scripts/audit_upstream_ui.py --packaged` 检查源文件和构建包内 63 个原版 HTML/CSS/图标逐字节一致。具体本地模型与桌面实测结果见 `RELEASE_VALIDATION.md`。
